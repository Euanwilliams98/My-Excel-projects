# Excel Retail & Sales Data Analysis

This project was completed during a **Data Technician Bootcamp** and focuses on analysing retail and sales data using Microsoft Excel. The goal was to clean, explore, and summarise sales information to generate useful business insights.

## Key Skills Demonstrated
- **Excel Formulas:** `SUM`, `SUMIF`, `AVERAGE`, `AVERAGEIF`, `DATE`, `MONTH`, `YEAR`, `UNIQUE`, `VLOOKUP`
- **Logical Functions:** `SWITCH` for categorising and organising data
- **Data Analysis:** Filtering and sorting datasets to identify patterns and trends
- **PivotTables:** Summarising and analysing large retail datasets efficiently
- **Data Visualisation:** Creating charts to present sales performance and trends

## Project Overview
Using a retail sales dataset, this project demonstrates how Excel can be used to perform data analysis, organise large datasets, and generate insights through formulas, PivotTables, and visualisations.

## Outcome
The analysis provides a clear overview of sales performance, product trends, and key metrics, showcasing practical Excel skills commonly used in **data analysis and business intelligence roles**.
